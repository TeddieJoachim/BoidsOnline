## BOIDS

Uses **C and WebAssembly (WASM)** for the boids simulation and JavaScript/WebGL for browser-side game logic and rendering.

The C code is compiled with **Emscripten**, which produces:
- A `.wasm` file containing the compiled C code.
- A `.js` file that loads the WASM module and provides the JavaScript interface.

I will give you a link to the installation page for Emscripten, then a brief bit on how to build the project, and run it locally.
---

## Project structure

The `src/` directory contains the C simulation. The `web/` directory contains the browser-side JavaScript and HTML. 
The `build/` directory contains the files generated by Emscripten. The generated `.js` and `.wasm` files are build outputs. Do not edit them manually.
`testC/` is a testing harness for the C code, you probably don't need to worry about this unless you mess around with memory in the C program, in which case 
there is a text file in this directory that instructs you on how to check for memory leaks/invalid writes etc.

## What is Emscripten?

Emscripten is a compiler toolchain that converts C/C++ code into WebAssembly so that it can run in a web browser.

We use the Emscripten SDK (`emsdk`) to install and manage the compiler.

Official installation instructions: https://emscripten.org/docs/getting_started/downloads.html

## Running/building the project locally
Use the Makefile I wrote. The syntax is: make [target]. 
eg "make clean" will remove old build files, "make serve" will start your local python server. It is a small file so poke around in it, hopefully everything is clear.

## Common problems

### `emcc: command not found` or `emcc is not recognized`

The Emscripten environment has not been activated in the current terminal.

- Windows: run `emsdk_env.bat` or open the Emscripten Command Prompt.
- macOS/Linux: run `source ./emsdk_env.sh` from the SDK directory.

### `Module._initializeBoids is not a function`

Check that:
- The C function is exported using `EMSCRIPTEN_KEEPALIVE` or `EXPORTED_FUNCTIONS`.
- The C function name matches the JavaScript call.
- You recompiled after changing the C code.
- You are calling the function with the leading underscore in JavaScript.

### `emscripten/emscripten.h` cannot be found

Make sure you are compiling with `emcc`, not `gcc`, and that the Emscripten SDK is activated.

### The browser cannot find `boidRunner.wasm`

Check that:
- You successfully compiled the C code.
- Both generated files are present in `build/`.
- The script path in `index.html` is correct.
- The generated `.wasm` file is being served from the expected location.

### Changes to C code do not appear in the browser

Recompile the project after changing any C source files. The browser loads the generated WASM file, not the original C code.

You may also need to hard-refresh the browser to clear cached files.
